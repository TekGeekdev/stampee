# Projet Web - Gestion d’un site de réservation

## 📌 Description

Ce projet a été réalisé dans le cadre d’un cours de projet développement web. Il s'agit d'un site de réservation structuré selon le pattern **MVC** (Modèle-Vue-Contrôleur), utilisant PHP, HTML, CSS et Twig pour le templating. Il permet la gestion d’utilisateurs, d'activités et de réservations via une interface et utilisateur.

## 🚀 Technologies utilisées

- PHP
- HTML / CSS
- Twig
- JavaScript
- MySQL
- MVC (architecture logicielle)

## 📁 Organisation du projet

Le projet est structuré en plusieurs sprints, chacun représentant une phase d’évolution du site :

- **Sprint 1 :** Mise en place de la structure MVC et création de la base de données.
- **Sprint 2 :** Création des pages utilisateur et des premières fonctionnalités dynamiques et sécurisation des accès.
- **Sprint 3 :** Intégration des réservations et gestion des filtres.

## 🧠 Retour d’expérience

Ce projet a été particulièrement formateur. Bien que j’aie rencontré des difficultés à élaborer des sprints détaillés en grande partie, car je n’ai pas reçu de cours spécifique sur la gestion de projet. Cette contrainte m’a obligé à me structurer par moi-même. Cela m’a permis de développer fortement mon **autonomie** et ma capacité à m'organiser.

J’ai également énormément appris grâce à une **consultation approfondie des documentations techniques**, que ce soit pour comprendre le fonctionnement du MVC, PHP, configurer correctement Twig ou optimiser les requêtes SQL. Ce projet est celui dans lequel j’ai **le plus appris depuis le début de ma formation**.

## ✅ Fonctionnalités principales

- Authentification des utilisateurs
- Gestion des activités (CRUD)
- Enchère avec interface utilisateur dédiée
- Tableau de bord utilisateur
- Sécurisation des accès
- Intégration responsive

## 🛠️ Installation

1. Cloner ce dépôt.
2. Configurer votre environnement local (PHP + MySQL).
3. Lancer le projet via un serveur local (XAMPP, WAMP, etc.).
